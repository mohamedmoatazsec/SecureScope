# Security Policy

## Reporting a vulnerability in SecureScope

If you find a security issue in SecureScope itself (for example a way for a scanned target to
influence the report in an unsafe way, or unsafe handling of input), please report it privately
rather than opening a public issue.

- Use GitHub's private vulnerability reporting on this repository
  (**Security → Report a vulnerability**), or
- Contact the maintainer through [LinkedIn](https://www.linkedin.com/in/mohamedmoatazsec).

Please include the version (`securescope --version`), steps to reproduce, and the impact as you
understand it. You will get an acknowledgement within a few days, and a fix or a clear answer
before any public disclosure.

## Scope reminder for users

SecureScope is an assessment tool. Running it against systems you are not authorised to test may
be illegal in your jurisdiction. The maintainers are not responsible for misuse.

## Supported versions

Only the latest release on the `main` branch receives fixes.
